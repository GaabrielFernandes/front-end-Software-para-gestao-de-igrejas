# Frontend Assembleia de Deus

Frontend em Angular para o sistema de gestão de membros (e futuras movimentações financeiras) de uma igreja.

## Status
🚧 Em desenvolvimento

## Stack
- Angular 18
- TypeScript
- Tailwind CSS (se estiver usando)
- (Opcional) PrimeNG

## Backend
Este frontend consome a API:
- https://github.com/GaabrielFernandes/api-assembleia-de-deus

## Como rodar local

### Pré-requisitos
- Node.js (LTS recomendado)
- Angular CLI (`npm i -g @angular/cli`)

### Instalação e execução
```bash
npm install
npm start
